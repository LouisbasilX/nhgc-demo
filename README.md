# National Health Supply Chain Digital Knowledge & Learning Platform

**Enterprise-grade simulation** of the Integrated Learning Management System / Digital E-Library proposed for NPSCMP & GHSC-PSM Nigeria under the U.S. Department of State EOI.

## Stack
- **Next.js 16** (App Router) + React 19
- **Tailwind CSS v4**
- TypeScript
- Deploy-ready for Vercel

## Portals
1. **Landing Page** — High-conversion institutional homepage
2. **Learner Portal** (`/learner`) — Pathways, progress, certificates
3. **Digital E-Library** (`/library`) — Smart search & resource management
4. **Command Center** (`/admin`) — National analytics & content studio

## Design System
- **60% Base**: Deep Navy `#0B1D36`
- **30% Secondary**: Soft surfaces & slate
- **10% Accent**: Teal `#0D9488` (CTAs / active states only)
- **Typography**: Playfair Display (headings) + DM Sans (body)
- Generous whitespace, WCAG-conscious contrast, mobile bottom navigation

## Run Locally
```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Simulation Notes
All buttons, navigation, filters, and CTAs are fully interactive. Toasts provide immediate feedback. No backend required — pure frontend demonstration of capability matching the Technical Proposal.

Government Ownership target: March 2027.
